
 # 📝 To-Do List with Study Timer

A simple and interactive To-Do List web application built using HTML, CSS, and JavaScript. This project helps users manage daily tasks efficiently and includes a built-in countdown timer for focused study/work sessions.

---

## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Saves tasks using Local Storage (data remains after refresh)
- Custom study timer with countdown
- Responsive and clean UI
- Beginner-friendly code structure

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

## 📁 Project Structure
ToDo-List/
│── index.html # Main webpage structure
│── style.css # Styling and layout
│── script.js # Task and timer functionality
│── README.md # Project documentation


---

## ⚙️ How to Run / Use

1. Download or clone this repository
   
2. Open the project folder.

3. Run `index.html` in any web browser.

4. Start using:
   - Add tasks using the input box.
   - Click a task to mark it completed.
   - Click ❌ to delete a task.
   - Enter study minutes and press **Start Timer**.
